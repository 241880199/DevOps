# 查询任务

- **端点**：`GET /v1/jobs/{job_id}`
- **适用**：四类任务共用
- **状态**：已采用，待双方确认后冻结

## 一、生产侧与消费侧

| 角色 | 谁 | 做什么 |
| --- | --- | --- |
| 生产侧 | 统一任务入口 | 受理四类任务、分配 `job_id`、登记状态与结果 |
| 消费侧 | 所有下游服务 | 轮询任务进展、取终态结果 |
| 消费侧 | 调度方与运维 | 判断该重试还是该处理结果、排查卡住的任务 |

创建接口只做受理（`202` + `job_id`），执行在后台进行，结果一律由本端点取回。理由见 `docs/ADR/ADR-001`。

## 二、约定内容

### 1. 返回体

一份 Job 分五组，四类任务共用同一套外层结构（完整定义见 `docs/contracts/01-公共数据结构.md`）：

| 组 | 字段 | 语义边界 |
| --- | --- | --- |
| Identity | `schema_version`、`job_id`、`trace_id` | 回答「这是什么、属于哪次流程」；创建后不可变 |
| Lifecycle | `status`、`job_type` | 回答「任务进行到哪一步」；不表达结果好坏 |
| Execution | `execution.created_at`、`.started_at`、`.finished_at`、`.attempt` | 任务级的时间与尝试次数，以服务端时钟为准 |
| input | `input` | 调用方提交并经服务接受的输入快照，创建后不可变 |
| result | `output`、`error` | 终态结果，成功产出与失败原因互斥 |

`execution` 始终存在；尚未发生的时间取 `null`（取空值，不是省略字段）。时间格式为 RFC 3339 / ISO 8601，UTC，毫秒精度。

### 2. 状态机

```
QUEUED ──> RUNNING ──> 任意终态
   │
   └───────────────> CANCELLED

终态：SUCCEEDED / FAILED / TIMED_OUT / CANCELLED
```

| 状态 | 语义边界 |
| --- | --- |
| `QUEUED` | 已受理，尚未开始。创建接口立即返回此状态 |
| `RUNNING` | 后台执行中 |
| `SUCCEEDED` | 结果可用 |
| `FAILED` / `TIMED_OUT` / `CANCELLED` | 系统执行错误，`error` 必填 |

终态一经到达不再变更；取消由调用方发起，取消后仍可查询。

### 3. 三条交付约束

1. `output` 与 `error` **只在终态出现**，`QUEUED` / `RUNNING` 阶段只返回任务元数据——消费方因此只需面对一种输出形状；
2. `SUCCEEDED` ⟹ 必有 `output`，且不得同时携带 `error`；
3. `FAILED` / `TIMED_OUT` / `CANCELLED` ⟹ 必有 `error`，且不携带 `output`。

### 4. 最重要的语义分界

**检出问题不等于执行失败。** 检测服务报出 MD / RD 说明它正常完成了工作，任务终态仍是 `SUCCEEDED`，发现写在 `output` 引用的报告产物里。把「发现 MD」写成 `FAILED` 会让调度器把一次成功分析当成基础设施故障重跑。见 `docs/contracts/03-系统错误与状态.md`。

同理，修复服务把所有候选都拒了也仍是 `SUCCEEDED`（`fixed` 为空、`rejected` 非空）。

### 5. 未登记的任务

`job_id` 未登记时返回 `404`。这一档尚无共享错误码，本地实现暂以状态码承载（见 `contracts/error-codes.md` 第 7 节）。

## 三、可执行的最小检查

| 用例 | 期望结果 |
| --- | --- |
| 创建任务后立即查询 | `200`，`status = QUEUED` |
| 执行过程中查询 | `status = RUNNING`，且既无 `output` 也无 `error` |
| 执行完成后再查询 | `status` 为终态；`SUCCEEDED` 带 `output`、不带 `error` |
| 查询不存在的 `job_id` | `404` |
| `job_id` 出现在创建请求里 | `400` |

| 项 | 状态 |

| 四类任务共用本端点 | 已采用（见 `docs/ADR/ADR-001`、`ADR-004`） |
| 状态取值与错误码分段 | 已采用（见 `docs/contracts/03-系统错误与状态.md`） |
