## 新增个人场景

建立 `main.c → config.h → extra.h → leaf_a.h`，预先同时创建 leaf_a.h 与 leaf_b.h。只把 extra.h 的 include 切换到 leaf_b.h，不改 main.c 或 Makefile，也不改变文件集合。

独立预期与实测一致：旧 key 失效，两目标刷新；actual 中 leaf_a.h 消失、leaf_b.h 出现；added 精确为 MD leaf_b.h，resolved 精确为 MD leaf_a.h；MD config.h、extra.h 与 RD unused.h 保留。随后只补声明，key 不变，两图复用，三项当前 MD 消除，仅 RD unused.h 保留。两阶段均与全量扫描比较。这比 E8 的单层包含新增/移除增加了多层依赖替换和声明修复覆盖。
