# 工作记录

契约阶段约定：**每人一份**，记录「读了什么、提出了什么问题、得到了什么回答、还有什么没解决」。

| 约定 | 说明 |
| --- | --- |
| 文件名 | 带自己的标识与所负责的环节，例如 `A1-BuildChecker.md`、`B2-MDFixer.md` |
| 内容 | 自定，不要求格式统一 |
| 为什么每人一份 | 契约阶段的讨论散在群聊与提交里，个人记录是唯一能还原「我提过什么、谁回答了什么」的东西；六个人写同一份会不断冲突 |

## 已有记录

- [A03-BuildChecker.md](A03-BuildChecker.md)：A03 接口文档完整性检查、E3 检测基线及 E4 BuildChecker 环境的个人记录。身份信息保留在正文，文件名按“小组标识-负责环节”命名。

**不代写他人的记录**——各人的记录由各人自己审核并提交。
